# Циферки (SimGenerator)

## Запуск в браузере

Откройте `game.html` в современном браузере. Игра хранит прогресс в localStorage.
Google Fonts загружаются из интернета; при отсутствии сети будут использованы
системные шрифты.

## Запуск на Android через Termux

Установите Termux из F-Droid, затем выполните:

```sh
termux-setup-storage
pkg install python
cd "/storage/emulated/0/Download/игры мои /SimGenerator"
python -m http.server 8000
```

Откройте в Chrome `http://localhost:8000/game.html`. Укажите фактический путь к
папке проекта, если она находится в другом месте. Если Termux запросит доступ к
файлам, подтвердите его.

## Сборка Android APK

В `android/README.md` описан WebView-проект для AndroidIDE / Android Studio.
Перед сборкой из корня проекта запустите:

```powershell
powershell -ExecutionPolicy Bypass -File .\android\sync-assets.ps1
```

Затем откройте папку `android` в AndroidIDE и соберите APK. WebView использует
WebViewAssetLoader для локальных файлов, а сохранение остаётся в WebView
localStorage.

## Игровые экраны

- Выдача, коллекция, роуминг, история, краш, рынок, аукцион, сделки и телефоны.
- Мини-игры: апгрейд, рулетка, кейсы, угадай цифру и мозаика.
- Профиль с Player ID, аватаром, ником и достижениями; рейтинг локальных NPC.
- Ежедневные задания, статистика, друзья, сезонные награды, косметика, витрина
  и уведомления.

Данные предыдущих версий сохраняются при добавлении новых полей профиля и игр.
Рейтинг, друзья и профиль работают локально на устройстве и не синхронизируются
между игроками.
